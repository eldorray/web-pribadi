# Chat AI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Private PIN-gated `/chat` page (Claude-web-like) for two people, backed by any OpenAI-compatible provider configured from `/admin/chat-ai`, with streaming, model/effort choice, image generation and PDF/DOCX/image attachments.

**Architecture:** Four new tables plus `SiteSetting` rows (group `ai`) for connection config. One `AiClient` service wraps Laravel `Http` for models, chat (SSE stream), and image generation (two modes). A cookie-based `ChatPin` middleware gates a full-page Livewire component `App\Livewire\Chat\Page`; admin config lives in `App\Livewire\Admin\ChatAi\Index`.

**Tech Stack:** Laravel 13, Livewire 4.2 (`$this->stream()`), Blade, Tailwind 4, PHPUnit 12, `smalot/pdfparser` (only new dependency).

**Spec:** `docs/superpowers/specs/2026-11-03-chat-ai-design.md`

## Global Constraints

- Only new dependency: `smalot/pdfparser`. DOCX via `ZipArchive`, markdown via `Str::markdown()`.
- API key never in HTML, Livewire payload, JS, logs, or exception messages. Stored with `Crypt::encryptString`.
- Every conversation/file query goes through the current `ChatUser`'s relation; foreign IDs → 404.
- PIN: 6 digits, `Hash::make`; 5 attempts/minute per IP; cookie lifetime 30 days.
- Attachments: `jpg,jpeg,png,webp,pdf,docx`, max 10 MB (`max:10240`) each, max 5 per message, stored on disk `local` under `chat/{chat_user_id}/`.
- `/chat` outside `TrackVisitor`, `<meta name="robots" content="noindex">`, not linked from public navbar.
- AI calls synchronous; `set_time_limit(180)` around image generation and streaming.
- History cap ~100 000 characters (drop oldest). Images sent as base64 only for the newest user message; older ones become `[gambar: <name>]`.
- Image mode: prompt = current message only. Image size `1024x1024`, `n: 1`.
- `reasoning_effort` (`low|medium|high`) sent only when model `supports_effort`.
- Markdown: `Str::markdown($text, ['html_input' => 'strip', 'allow_unsafe_links' => false])`.
- UI text Indonesian. Use existing site palette/fonts, not Claude branding. Inputs 16px on mobile.
- Follow existing code style (`declare(strict_types=1)` in new files, Pint).

## Review Focus

- Provider returns non-JSON / HTML error page (wrong base URL) → readable error bubble, not a 500. Test in Task 3 (`test_non_json_error_becomes_ai_exception`).
- Stream ends with no `content` (reasoning only, or empty) → saved assistant message shows "(Tidak ada jawaban)" instead of blank. Test in Task 6.
- API key field submitted empty in admin → existing key kept, not wiped. Test in Task 4.
- PIN changed in admin while partner is logged in → old cookie rejected. Test in Task 2.
- Corrupt/encrypted PDF or non-zip `.docx` → extractor returns null and user sees "tidak bisa dibaca", no exception. Test in Task 5.

### Task 3: AiClient service

**Files:**
- Create: `app/Services/AiClient.php`, `app/Services/AiException.php`
- Test: `tests/Unit/AiClientTest.php` (extends `Tests\TestCase`, uses `RefreshDatabase`)

**Interfaces:**
- Consumes: `SiteSetting` keys `ai_base_url`, `ai_api_key` (encrypted), `ai_image_mode` (`images`|`chat`, default `images`).
- Produces (`App\Services\AiClient`, resolve via container):
  - `listModels(): array` — returns `list<string>` of `data[].id`.
  - `chat(array $messages, string $model, ?string $effort, ?callable $onDelta = null, ?callable $shouldStop = null): array{content: string, truncated: bool}` — `stream: true` when `$onDelta` given; parses SSE lines `data: {...}` / `data: [DONE]`; collects `choices[0].delta.content`; calls `$onDelta(string $chunk)`; breaks and sets `truncated` when `$shouldStop()` is true. Without `$onDelta` sends non-stream and reads `choices[0].message.content`.
  - `generateImage(string $model, string $prompt): string` — returns raw image bytes. Mode `images`: `POST /images/generations` (`b64_json` or `url`, fetch URL). Mode `chat`: `POST /chat/completions` with `modalities: ['image','text']`, read `choices[0].message.images[0].image_url.url` (data URL → decode, else fetch).
  - `static setApiKey(string $plain): void`, `static hasApiKey(): bool`.
  - Throws `AiException(string $userMessage)` for non-2xx, non-JSON, missing config, missing image. Message includes HTTP status and provider `error.message` if present; never the key.
  - Base URL trimmed of trailing `/`; timeout 120s (connect 10s).
